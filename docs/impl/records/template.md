# Task Record Template

## Work contract

Paste the original plan task in a fenced block, or state the scope of the direct request.

## Implementation and decisions

Summarize the change and any material tradeoffs or authorized scope changes.

## Acceptance evidence

Record the status as open or accepted. List commands or artifacts, their results, and any gate
that still needs evidence. For research, explain how a negative result meets the declared gate and
link the question's section in the [closed-research register](../future-research.md).

## Handoff

Name remaining work and its owning task ID. For planned work, record the before and after task
counts and any registry or dependency changes.
