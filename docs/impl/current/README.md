# Current-State Pages

This directory holds one page per product area. Each page describes behavior available now:
interfaces, modules, commands, verification methods, and durable findings. It starts empty in a new
project. Add an area's page when its first task is accepted, and link it from the
[areas index](../current.md#areas) in the same change.

The tooling, starter command, and documentation checks that come with the template are described in
the [development guide](../../guide/development.md).
